# 💻 Package os (Operating System)

---

## 📌 Pengenalan Package `os`

Go-Lang menyediakan package bawaan bernama `os` yang berisikan fungsionalitas untuk mengakses fitur-fitur sistem operasi secara platform-independent (bisa berjalan di Linux, macOS, maupun Windows tanpa perubahan kode).

- **Fungsi Utama**: Berinteraksi langsung dengan sistem operasi yang menjalankan program Go (membaca argumen CLI, mendapatkan hostname, membaca/menulis file, memanipulasi environment variable, proses terminasi program, dll).
- **Cross-Platform**: Kode yang kita tulis menggunakan package `os` otomatis disesuaikan implementasinya dengan sistem operasi target ketika di-compile.
- **Dokumentasi Resmi**: [https://pkg.go.dev/os](https://pkg.go.dev/os) atau [https://golang.org/pkg/os/](https://golang.org/pkg/os/)

---

## ⚙️ Fitur Populer di Package `os`

### 1. Membaca Command Line Arguments (`os.Args`)
`os.Args` adalah slice bertipe `[]string` yang menampung seluruh argumen baris perintah saat program dijalankan.
- **Index ke-0 (`os.Args[0]`)**: Merupakan path binary/eksekusi program itu sendiri.
- **Index ke-1 ke atas (`os.Args[1:]`)**: Argumen tambahan yang diinput oleh user via terminal.

Contoh eksekusi:
```bash
go run main.go hello world
# os.Args[0] = path/to/binary
# os.Args[1] = "hello"
# os.Args[2] = "world"
```

### 2. Mengambil Hostname (`os.Hostname()`)
Digunakan untuk mengetahui nama komputer/mesin tempat program sedang berjalan.
- Mengembalikan 2 nilai: `(name string, err error)`.

### 3. Fungsi Umum Lainnya di Package `os`
| Fungsi | Deskripsi |
| :--- | :--- |
| `os.Getenv("KEY")` | Mengambil nilai dari *Environment Variable* sistem operasi |
| `os.Setenv("KEY", "VALUE")` | Mengatur nilai *Environment Variable* baru |
| `os.ReadFile("path/file.txt")` | Membaca seluruh isi file menjadi `[]byte` |
| `os.WriteFile("path/file.txt", data, perm)` | Menulis data ke file dengan permission tertentu |
| `os.Exit(code)` | Menghentikan eksekusi program seketika dengan status code (0 = normal, 1 = error) |

## 💻 Contoh Implementasi di Kode

File: [`standard_library/os.go`](../../standard_library/os.go)

```go
package standardlibrary

import (
	"fmt"
	"os"
)

func OsFunction() {
	// 1. Mengakses Command Line Arguments
	args := os.Args
	for _, arg := range args {
		fmt.Println(arg)
	}

	// 2. Mengambil Hostname Komputer
	hostname, err := os.Hostname()
	if err == nil {
		fmt.Println("Hostname:", hostname)
	} else {
		fmt.Println("Error hostname:", err.Error())
	}
}
```
