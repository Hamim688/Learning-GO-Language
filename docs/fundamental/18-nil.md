# 🈳 Nil

---

## 🎯 Konsep Data Nil

- Biasanya di dalam bahasa pemrograman lain, objek yang belum diinisialisasi maka secara otomatis nilainya adalah `null` atau `nil`.
- Berbeda dengan Go-Lang, di Go-Lang saat kita membuat variabel dengan tipe data tertentu, maka secara otomatis akan dibuatkan nilai bawaan (*default value*) nya.
- Namun di Go-Lang ada data **nil**, yaitu data kosong.
- Nil sendiri hanya bisa digunakan di beberapa tipe data tertentu, seperti:
  - Interface
  - Function
  - Map
  - Slice
  - Pointer
  - Channel
