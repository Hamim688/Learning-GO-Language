🔗 **Source Code terkait:** [new.go](../../fundamental/new.go)

---

## 🎯 Konsep Operator `new`

- Sebelumnya untuk membuat pointer kita menggunakan operator `&`.
- Go-Lang juga memiliki fungsi **`new`** yang bisa digunakan untuk membuat pointer.
- Namun fungsi `new` **hanya mengembalikan pointer ke data kosong**, artinya tidak ada data nilai awal (otomatis diisi nilai *zero value* dari tipe data tersebut).
