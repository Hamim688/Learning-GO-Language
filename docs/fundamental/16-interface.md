# 🔌 Interface & Implementasi Interface

---

## 🎯 Konsep Interface

- **Interface** adalah tipe data *Abstract* yang tidak memiliki implementasi langsung.
- Sebuah interface berisikan definisi-definisi method.
- Biasanya interface digunakan sebagai **kontrak** logika program.

---

## ⚙️ Implementasi Interface

- Setiap tipe data yang sesuai dengan kontrak interface, secara otomatis dianggap sebagai interface tersebut (*implicit implementation*).
- Sehingga kita tidak perlu mengimplementasikan interface secara manual menggunakan kata kunci khusus.
- Hal ini berbeda dengan bahasa pemrograman lain di mana saat membuat interface, kita harus menyebutkan secara eksplisit akan menggunakan interface mana.
