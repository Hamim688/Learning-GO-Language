# 🏗️ Struct & Struct Method

---

## 🎯 Konsep Struct

- **Struct** adalah sebuah template data (*prototype*) yang digunakan untuk menggabungkan nol atau lebih tipe data lainnya dalam satu kesatuan.
- Struct biasanya digunakan sebagai representasi data dalam program aplikasi yang kita buat.
- Data di dalam struct disimpan dalam variabel-variabel yang disebut **field**.
- Sederhananya, struct adalah kumpulan dari field.

---

## 🛠️ Membuat Data Struct

- Struct adalah template data atau prototype data, sehingga **tidak bisa digunakan langsung**.
- Namun kita bisa membuat data/object (*instance*) dari struct yang telah kita buat.
- Pengisian data struct bisa dilakukan secara manual per-field atau menggunakan sintaks *struct literal*.

---

## ⚙️ Struct Method

- Struct adalah tipe data seperti tipe data lainnya, sehingga bisa digunakan sebagai parameter untuk function.
- Namun jika kita ingin menambahkan fungsi ke dalam struct (sehingga seakan-akan sebuah struct memiliki function tersendiri), kita menggunakan **Struct Method**.
- **Method** adalah function yang ditempatkan menempel pada tipe data struct tertentu.
