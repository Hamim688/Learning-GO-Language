# 🔒 Access Modifier

🔗 **Source Code terkait:** [helper.go](../../fundamental/access_modifier/helper.go)

---

## 🎯 Konsep Access Modifier di Go-Lang

- Di bahasa pemrograman lain, biasanya ada kata kunci yang bisa digunakan untuk menentukan *access modifier* terhadap suatu function atau variable.
- Di Go-Lang, untuk menentukan *access modifier*, cukup dengan **nama function atau variable**.

---

## 🔑 Aturan Penamaan Access Modifier

- **Exported (Public):** Jika namanya diawali dengan **huruf besar**, maka artinya bisa diakses dari package lain.
- **Unexported (Private):** Jika dimulai dengan **huruf kecil**, artinya tidak bisa diakses dari package lain.
